A one-page editorial infographic, "THE DAY IN WORLD NEWS", summing up Thursday 19 November 2026 in one 1024x1024 image: three feature stories (Shenzhen summit, Crimea Bridge, GTA VI), six further world stories, a numbered world map, the day's four headline numbers, and an "Also on Thursday 19 November" box. All stories and numbers come from the verified list in SOURCES.md. The image is entry.png; build_image.py redraws it deterministically, and main.py copies it to the output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
